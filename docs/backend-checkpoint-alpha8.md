# LX Native 0.3.0-alpha.8 后端检查点

日期：2026-10-08。Windows x64/MSVC，Rust/Cargo 1.99.0，SQLite schema 7，后端协议1。兼容基线为 LX Music Desktop v2.12.6 提交 `ad95d5091c9ed689fa72b5e5c849df65f5a679ce`。

## 可运行范围

设备选择采用稳定CPAL身份，目标偏好、实际端点和Memory模式分别表示。枚举、打开、关闭、格式交接和重连由有归属的设备工作线程执行；候选失败保留原输出，设备暂失保留原PCM消费者、预取帧、token、seek epoch和媒体时钟。运行失效可重建同一端点，重连与清单刷新采用有限频率；实体端点发声独立验收。

静音保留保存的音量并持续推进真实内容时钟，设备拓扑暂停只作用于正在播放且实际端点发生变化的情况。暂停通知受播放意图序号保护，后续播放或更换媒体可使旧通知失效。偏好经过旧文件默认值读取和提交校验；存储失败不覆盖原文件、运行偏好、媒体或缓存。完整API见[设备接口](audio-output.md)。

初始输出延迟到明确设备选择/刷新或已批准媒体准备完成；Memory选择/刷新不创建渲染线程。异步输出准备期间保存真实DecoderReady，切换不重复解析地址、启动解码或清空缓存。关闭期限保留真实资源拥有者，后端actor持续等待可重试超时，实际join后才报告Closed和Stopped。
