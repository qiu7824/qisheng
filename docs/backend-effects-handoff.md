# 音效银行交接

`HandoffBounds` 绑定实际旧音效银行的拥有者、流身份、PCM 格式、已批准重放容量、延迟和响应长度。格式改变前，准备拥有者通过 `HandoffReservation::reserve` 预留新银行、旧媒体前缀、完整原始区间标签和旧尾音存储；预算包含实际重放容量、最终待呈现帧、完整响应尾长和旧延迟。额度、分配、格式或取消错误保留候选银行，不关闭正在使用的端点。

准备工厂使用同一 `EffectsBankPool` 在 FFT、滤波与银行准备前取得不可独立释放的真实槽位；最多两个银行同时处于准备、活动或退休状态。唯一 `CountedBank` 持有实际银行、不可变响应来源与边界记录、槽位。取消、关闭和移入返回队列均不释放槽位；实际拥有者销毁银行后才归还。共享边界的配额放在边界对象内部，外部注册记录持有 `Arc` 时继续占用。

实际回调在安装时公布银行身份，拥有者可据此查找工厂生成的原始记录。锁定握手同时匹配银行、媒体、源 epoch、采样率和设备通道；回调确认后冻结替换并归还未选择的候选，同时继续当前媒体输出。取消只申请解除锁定，必须等待真实回调确认；硬流变化拒绝旧锁定。队列移动和锁定确认不能替代实际银行交回。

旧回调关闭并交回实际银行后，`capture` 验证同一拥有者与连续完整标签。`advance_capture` 每次处理最多 1024 步，保存已经经过旧 DSP 的 PCM，取消或错误保留实际银行、已保存 FIFO 和待消费凭证。只有 FIFO 真正写入对应样本与完整标签后，才产生一次性转移凭证；转移不增加旧银行的媒体或尾音呈现计数。

格式相同时不创建第二个银行，保留原来的完整 DSP 状态。格式改变使用原生线性 PCM 重采样和明确的设备布局折叠策略：旧银行已经接受而尚未呈现的媒体只输出一次，其原始输入仅提供区间标签，不重新进入新图。下降采样也保留从首个原始 begin 到最终 end 的完整区间。

取消后的银行尚未呈现任何前缀、尾音且未接受未来输入时，拥有者可以准备另一个目标格式的真实银行，并保留原捕获 FIFO、标签及原始采样率。替换成功后先销毁被替换的银行，再释放其真实名额和注册记录；失败保留原交接及完整候选银行。已确认呈现的交接不使用此重定向入口。

前缀已经部分呈现、尚无尾音确认且目标银行未接受未来输入时，剩余前缀使用独立的恢复入口。拥有者保存真实确认位置的归一化有理网格，目标采样率改变后从该位置继续读取原始 FIFO；首个原始区间起点为实际已确认末点，最终区间仍覆盖原末点。预留与整数容量检查在拥有者上完成，回调只读取准备好的网格。未确认副本失效，凭证序号保持递增；原音频不重新进入 DSP。

仍在活动端点输出保留前缀或尾音时，第二次设备选择在锁定确认后检查真实交接状态。尚未排空的交接保留当前端点，拒绝关闭旧回调；排空后由设备拥有者重新尝试最新选择。

设备失效后，实际关闭回调交回的银行由设备拥有者直接处理；先退休未选择的等待候选，再以同一不可变响应记录准备目标格式并捕获。此路径不伪造回调锁定确认。停止、源失败、源取消和 seek 的硬失效在拥有者上销毁实际交接并清除旧、新注册记录；普通解码暂停保留尚未呈现的音频。没有不可变准备记录的兼容银行只允许同格式恢复；不同格式恢复保留原银行并返回明确错误。

回调先读取旧媒体前缀，实际写入最终设备槽位后才确认呈现；失败或暂停保留同一个帧。所有公开帧字段必须与真实待呈现副本完全一致，修改样本、时钟或处理标签的副本不能作为凭证。旧媒体前缀全部确认后，新银行才接受未来输入；旧无时钟尾音可叠加到未来输出，不能推进原始媒体时钟。旧尾音保留捕获时的空间位置和旧设备混音，再按声明的原生布局映射。

FFT、输入、重叠、输出与卷积区间标签均在准备拥有者上进行受配额管理的固定堆分配。银行按值转移不会携带大段内联数组，回调处理、重置和呈现不更换缓冲。退休的旧银行交回实际拥有者销毁，回调不销毁银行或 FIFO。

前缀排空后，目标银行已经接受未来媒体而旧尾音仍未排空时，设备拥有者捕获该银行尚未呈现的真实输出。旧尾音从实际确认后的剩余位置叠加到捕获媒体及尾音，使用故障端点的采样率和设备布局形成一份规范 FIFO；合并过程中保留两份原存储及真实银行名额。完整捕获与合并结束后销毁旧银行、释放其名额和注册记录，新端点仅重采样已经处理过的混合 PCM。旧尾音不构造媒体时钟，不重复进入新 DSP；合并取消后由存储游标续行，不重复相加。

定向验收包括完整区间、1/48 下降采样、同格式原银行保留、真实容量预算、错误拥有者、取消与重试、修改凭证拒绝、原始计数不伪造、尾音无时钟和回调无堆操作。原始 Output、DeviceOwner、DSP、工厂和交换模块的限定范围运行 125 项测试通过，覆盖真实卷积响应的跨格式切换、取消重定向、带等待候选的故障恢复、部分前缀恢复及暂停中的同 epoch 失败和取消。2051 帧真实响应的端点测试验证未来媒体、部分旧尾音确认后的 16 kHz 双声道至 24 kHz 单声道及 32 kHz 双声道恢复，首帧逐通道与实际待呈现媒体加旧尾音的独立样本值比较，前缀不重新读取源，时钟连续到原末点，真实名额归零。设备端点使用原始 MockBackend 测试夹具；物理端点、长响应性能、浏览器采样器等价性及完整发行验收分别执行。
