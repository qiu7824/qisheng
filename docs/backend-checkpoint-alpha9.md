# LX Native 0.3.0-alpha.9 后端检查点

日期：2026-10-08。Windows x64/MSVC，Rust/Cargo 1.99.0，SQLite schema 7，后端协议1。兼容基线为 LX Music Desktop v2.12.6 提交 `ad95d5091c9ed689fa72b5e5c849df65f5a679ce`。

## 可运行范围

十段peaking EQ在Device/Memory共同的真实PCM渲染链执行，频段31–16000Hz、Q1.4、有限增益−15至+15dB，并提供九个上游预设及flat复位。系数和f64声道历史采用固定存储；两个静态滤波器bank处理同一输入帧，以约20ms完成过渡，过渡期间的更晚参数保留在单一待应用槽中。准备系数及设备采样率适配在回调之外执行，不增加来源读取次数。

实际输出Nyquist及以上的频段保存请求值并使用unity；平直状态保持f32样本、各声道互相隔离。媒体更换、seek、暂停、设备切换、断流预取及EOF边界清除旧滤波历史；静音在最终增益阶段执行并保持内容时钟。持久目标、回调确认目标、过渡剩余帧、实际限幅和非有限样本统计分别表示，接口见[均衡器接口](equalizer.md)。

空缓存初始化中断采用受管所有权证明恢复：根OS锁保持有效，只接纳完整精确header、无正文、无命名空间或外来条目的根目录，并预先核对配额与取消。已有正文、损坏或非同属header、外来字节及重解析点保持拒绝覆盖。Windows通过已持有锁的文件句柄校验锁内容。
