# LX Native 0.3.0-alpha.7 后端检查点

日期：2026-10-08。Windows x64/MSVC，Rust/Cargo 1.99.0，SQLite schema 7，后端协议1。兼容基线为 LX Music Desktop v2.12.6 提交 `ad95d5091c9ed689fa72b5e5c849df65f5a679ce`。

## 可运行范围

持久编码音频以真实解析上下文和精确URL建立稳定数据键；当前批准、源会话与流序号保持独立。跨播放及冷进程重开使用强ETag/长度验证后读取完整SHA校验块，200忽略Range只复用受保护的完整区间，不虚报服务器Range能力。v2索引、正文保护FD、别名物理去重、维护配额、clear/CAS和可读时点均由有归属I/O worker执行。见[编码复用](encoded-reuse.md)。

图片缓存提供四命令、五查询及事件。内置Picture、元数据URL、本地嵌入图与同一SourceWorker的local pic经过独立授权、元数据fence和完整JPEG/PNG/GIF/WebP解码；编码字节SHA去重、离线再验证及64KiB分页具有真实执行链路。逻辑配额与共享DB/WAL物理统计分列，见[图片接口](artwork-cache.md)。

真实429对同一已批准URL延迟2/4秒，最多两次重试；暂停、停止、元数据和源变化取消计时器。401/403/404/410对实际曲目最多两次强制URL刷新，再在启用自动切源时排除已失败平台、选择真实原生候选，每个新地址仍待批准。原始列表、显式音质和当前权限保持校验，阶段失败如实报告Error或未加载URI的Idle加后端错误，不虚构音频状态。
