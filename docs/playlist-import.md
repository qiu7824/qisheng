# 栖声歌单导入

点击左侧「歌单」旁的加号，选择「通过链接导入歌单」或「导入歌单文件」。

## 链接导入

选择对应平台，粘贴完整分享链接或歌单 ID，然后点击「导入」。支持小我、小狗、小Q、小云和小咪的平台歌单。链接与所选平台必须对应。

程序完整读取歌单分页后创建本地歌单；读取失败、取消或超过容量限制时不保存不完整结果。一次最多导入 50,000 首。导入不触发播放，不授予音源运行权限，也不自动批准音频地址。

## 文件导入

支持 LX 歌单格式的 `.lxmc`、JSON 与 gzip 文件，以及单个歌单和多个歌单备份。选择文件后显示确认窗口，确认前不修改歌单。确认导入会替换相同歌单 ID 的曲目，其他歌单保留。导入结果持久化保存。

完整设置备份不作为歌单文件导入，以免改动播放、同步及音源设置。本地音频路径属于元数据，需要通过添加音乐文件夹或导入本地音频取得文件访问权。

可以将歌单文件拖入窗口，也可以在读取过程中取消。损坏文件会显示错误，可重新选择有效文件。
