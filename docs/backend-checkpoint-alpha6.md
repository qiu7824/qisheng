# LX Native 0.3.0-alpha.6 后端检查点

日期：2026-10-07。平台：Windows x64/MSVC，Rust/Cargo 1.99.0，SQLite schema 6，后端协议1。兼容基线为LX Music Desktop v2.12.6提交`ad95d5091c9ed689fa72b5e5c849df65f5a679ce`。

## 可运行范围

保留独立后端、五平台SDK、源会话、事务列表/队列、四轨歌词、块流式音频、真实PCM、缓存I/O隔离及资产预加载。跨平台元数据匹配保留实际ID、hash、quality和排序理由；标题/艺术家/时长及版本词约束阻止错误同名替换，每平台选择一个真实候选。

schema 6保存URL信息及匹配记录，原曲/实际解析DTO、实际quality、自定义源SHA与批准策略共同限定复用。信息命中不下载音频，不恢复媒体许可；每次精确URL批准再核对当前列表和源会话。非strict换源逐候选重算quality，严格请求保留明确质量限制；逻辑列表保持原曲，快照可投影实际替代候选。

前景与预加载失败保留真实HTTP状态、媒体错误和URL摘要。传输401/403/404/410使缓存失效，对实际曲目最多强制刷新两次，每个地址仍待批准；源繁忙在同会话中延迟2/4秒、最多三次请求。元数据变化、取消、源切换与缓存清理后的旧结果不写仓，终态不报告假成功或留下busy。

完整搜索默认TTL7天，部分平台失败保存诊断并保留30秒；URL默认TTL15分钟。每个信息表4096行/8MiB并实施LRU和事务回滚，不增加用户revision/outbox。接口和边界见[媒体解析](media-resolution.md)。
